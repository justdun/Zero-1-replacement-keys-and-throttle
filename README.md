# Zero-1-replacement-keys-and-throttle

Please find the STL files for my replacement Hornby Zero 1 prototype throttle and low profile keys here!

Includes:
* Replacement throttle inspired by Hornby's 1979 catalogue photo of prototype
* Replacement keypad keys to work with DK Hyde's replacement keypad PCB (https://github.com/dkhyde/Zero-1), inspired by 1979 catalogue photo of prototype
* Replacement forward/reverse keys to match keypad keys
